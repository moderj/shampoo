# React Development

> _Estimation time: 10-14 Days_

---

React is the most popular JavaScript library for building user interfaces. This path will take you from the absolute basics to understanding the deep internal mechanics of the framework.

We follow a "Learn by Doing" approach, heavily supplemented by the excellent official React documentation.

**_Learning objectives:_**

At the end of this path, you'll be able to:

- Build complex interactive UIs with React
- Understand and apply the React mental model
- Manage state effectively using Hooks
- optimizing performance with memoization and concurrent features
- Handle side effects, data fetching, and complex component hierarchies

## The Path

### 1. [React Foundations](React/Foundations)
Start here. Understand the core concepts: Components, JSX, Props, and State.

### 2. [Project: Tic-Tac-Toe](React/Tutorial-TicTacToe)
Build your first interactive React application following the official tutorial.

### 3. [React Deep Dive](React/Deep-Dive)
Master the framework. A comprehensive journey through the entire React API, Hooks, best practices, and advanced concepts.

### 4. [Project: Call of Duty](React/Project-Call-Of-Duty)
The final boss. Build a full-stack React application with Material UI, Forms, Tables, Maps, and global state management.
