## Part 1: The Quick Start

The React learning guide covers 80% of the React concepts you will use on a daily basis.
Let's start with basics:

**Task:**
Read the **[Quick Start](https://react.dev/learn)** section on the official React docs.

**Focus on these sections:**
1. **Creating and nesting components**: Notice how components are just functions.
2. **Writing Markup with JSX**: It looks like HTML, but it's JavaScript.
3. **Adding Styles**: `className` instead of `class`.
4. **Displaying Data**: Using curly braces `{}`.
5. **Conditional Rendering**: Using `?` and `&&`.
6. **Rendering Lists**: Using `.map()` and `key`.
7. **Responding to Events**: Passing functions as props.
8. **Updating the Screen**: Using `useState`.
9. **Sharing Data**: Lifting state up.

> **Note:** Do not just skim! Type out the examples in the documentation's interactive sandboxes.

## Part 2: Thinking in React

React is not just a library; it's a mental model. How you break down a design into components is crucial.

**Task:**
Read **[Thinking in React](https://react.dev/learn/thinking-in-react)**.

**Key Takeaways to look for:**
1. **Step 1**: How to break a UI into a component hierarchy.
2. **Step 2**: Building a static version first (no state).
3. **Step 3**: Identifying the minimal representation of UI state.
4. **Step 4**: Identifying where state should live (common parent).
5. **Step 5**: Adding inverse data flow.

1. What is the difference between Props and State?
2. Why must component names start with a capital letter?
3. What happens when you call a state setter function?
4. How do you pass data from a child component to a parent component?
