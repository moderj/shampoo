# Frontend Development

> _Estimation time: 10-14 Days_

---

Frontend development is the practice of building the user interface and user experience of web applications. It involves creating the visual elements that users interact with directly in their browsers.

In this path you will learn the three core technologies of frontend development: HTML for structure, CSS for styling, and JavaScript for interactivity. You'll understand how these technologies work together to create modern, responsive, and interactive web applications.

This learning path will help you build the skills needed to create user interfaces, work with modern frontend frameworks, and understand how the browser renders web content.

This learning path includes the following modules:

- [HTML](Frontend/HTML) - Structure and semantics
- [CSS](Frontend/CSS) - Styling and layout
- [Frontend JavaScript](Frontend/Frontend-JavaScript) - Browser-side interactivity (aka javascript vanilla)

**Hands-On Practice:**

Throughout this learning path, you'll build a simple **Task List** application:

1. **HTML**: Create the basic structure
2. **CSS**: Add basic styling and layout
3. **JavaScript**: Make it interactive

The exercises are intentionally concise (5-20 minutes each) - this training focuses on understanding concepts rather than building a complex application. In real development, you'll use frameworks and CSS libraries that handle much of this for you.

Requirements:

- Basic understanding of programming concepts
- Text editor (VS Code recommended) [setup](Setup)

**_Learning objectives:_**

After completing this learning path, you'll be able to:

- Create semantic HTML documents with proper structure
- Style web pages using modern CSS techniques including Flexbox and Grid
- Add interactivity to web pages using JavaScript
- Build responsive layouts that work on all device sizes
- Debug frontend issues using browser developer tools
