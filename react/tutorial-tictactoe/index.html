# Setup

The React documentation provides a starter sandbox for this tutorial. Follow the official setup instructions to get started.

Task:

  1. Go to the Tutorial: Tic-Tac-Toe page.
  2. Follow the "Setup for local development" section.
  3. This involves downloading the starter code sandbox and unzipping the archive on your machine.
  4. Once extracted, navigate to the folder in your terminal and run the setup commands provided in the tutorial.

Note: The tutorial provides specific instructions for setting up the project locally. Make sure to follow those steps carefully.

# Features you will implement:

  1. The Board: Rendering squares using loops.
  2. Interactivity: Clicking squares to fill them.
  3. State Management: Checking for a winner.
  4. History: Storing past moves (immutability).
  5. Time Travel: Jumping back to previous moves.

# Challenge (Optional)

After finishing the tutorial, try these extra improvements listed at the end of the doc:

  1. For the current move only, show "You are at move #..." instead of a button.
  2. Rewrite Board to use two loops to make the squares instead of hardcoding them.
  3. Add a toggle button that lets you sort the moves in either ascending or descending order.
  4. When someone wins, highlight the three squares that caused the win.
  5. When no one wins, display a message about the result being a draw.
